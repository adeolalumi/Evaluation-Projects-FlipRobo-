# Evaluation Projects FlipRobo

Portfolio of Jupyter Notebook projects focused on exploratory data analysis, predictive modeling, model comparison, and business insight generation.

The repository contains multiple applied machine learning exercises across pricing, HR analytics, sports performance, insurance fraud, lending, weather, and restaurant data.

## Projects Included

| Project | Focus |
| --- | --- |
| Avocados Project | Avocado price analysis and regression modeling |
| Baseball Win Predict | Team performance analysis and win prediction |
| Census Project | Income classification |
| Global Power Plant Project | Power plant data analysis and predictive modeling |
| HR Project | Employee attrition analysis and classification |
| Insurance Claim Fraud | Automobile insurance fraud detection |
| Loan Application Status | Loan approval prediction |
| Rain Falling Forecast | Rainfall forecasting and classification |
| Temperature Project | Temperature forecasting |
| Zomato Restaurant | Restaurant data analysis archive |

## Techniques Used

- Exploratory data analysis and visualization
- Data cleaning and outlier handling
- Feature engineering and encoding
- Regression and classification modeling
- Cross-validation and model comparison
- Model persistence with `joblib`

## Tech Stack

Python, Jupyter Notebook, pandas, NumPy, scikit-learn, XGBoost, joblib

## How To Use

```powershell
python -m venv .venv
.\.venv\Scripts\activate
pip install pandas numpy scikit-learn xgboost matplotlib seaborn jupyter joblib
jupyter notebook
```

Open the notebook inside the project folder you want to explore.
